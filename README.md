# Customer Churn Analysis

## 📌 Project Overview
This project analyzes customer subscription data to uncover behavioral patterns behind cancellations, compute core retention and financial metrics (such as Churn Rate, MRR Loss, and CLV), and provide data-driven business insights to reduce customer churn.

---

## 🎯 Objectives & Key Metrics
* **Baseline Churn Rate:** Computed overall customer cancellation percentage across the subscriber base.
* **MRR Loss:** Quantified monthly recurring revenue lost from churned accounts.
* **Customer Lifetime Value (CLV):** Estimated average customer value based on tenure and monthly charges.
* **Segment Breakdown:** Evaluated churn rates across contract types (`Month-to-Month`, `One Year`, `Two Year`) and late payment frequencies.
* **Visualizations:** Generated comparative bar plots and tenure distribution boxplots.
